## 3. Process Crash & Interruption Resilience

- **Drift SQLite ACID Boundaries**: Operations write atomically to disk within SQLite WAL mode transactions. Interrupting process execution during entry creation leaves disk storage uncorrupted.
- **Sync Queue Recovery Service**: `SyncQueueRecoveryService` inspects pending outbox records upon application launch, identifying partially transmitted operations and resuming sync without duplicating events.
